# G502 X PLUS（MR0089）与 NuPhy Kick75

这份配置适用于 MacBook 发送输入、Windows 11 x64 接收输入。鼠标接收器插在 Mac，
Kick75 也连接 Mac（蓝牙、2.4G 或有线）。两台电脑在同一局域网，Windows 蓝牙不参与转发。

## 安装

两端都重新构建，方法见仓库 README。Mac 需要 macOS 15 以上，并授予辅助功能和输入监控权限。
旧 Windows 端不认识新增动作，不能只更新 Mac。

## 按钮配置

在 Mac 的 Unictrl 设置中开启 **G502 X custom buttons → Use F13 / F14 / F15 as mouse actions**。
默认关闭，旧配置升级后也不会自动占用键盘上的 F13–F15。

在 G HUB 中，使用“按键”分配单个功能键，替换以下三个原来的软件宏：

| 原功能 | G HUB 新分配 | 鼠标在 Mac | 鼠标在 Windows |
| --- | --- | --- | --- |
| 虚拟桌面左 | F13 | 上一个桌面 / Space | 上一个虚拟桌面 |
| 虚拟桌面右 | F14 | 下一个桌面 / Space | 下一个虚拟桌面 |
| 音量静音 | F15 | Mac 静音切换 | Windows 静音切换 |

建议把三个单键分配保存到鼠标板载配置，再退出 G HUB 验证它们仍能产生 F13/F14/F15。
如果 G HUB 使用软件分配，也必须输出这三个单独按键，而非原来的组合键宏。
此开关会保留所有设备发出的 F13/F14/F15：键盘手动按这些键也会触发相同动作。
其他 G HUB 宏、输入法或听写软件生成的按键不会因此获得通用转发权限。

保留 DPI 增加、左右键、中键、上下滚动、前进/后退与横向滚动的现有配置。
横向滚动必须输出标准水平滚轮事件；本次不更改其协议。
“群控”按钮不做映射，也不修改它的 G HUB 配置。本适配不保证该宏会在 Windows 执行。

Mac 在“系统设置 → 键盘 → 键盘快捷键 → 调度中心”中启用 Control+左/右方向键切换空间。
两台电脑各创建至少两个桌面，才能验证左右切换。Mac 快捷键若已自定义，需恢复这两个绑定。
Kick75 建议保持 Mac 模式，Windows 端的 Keyboard layout 选择 **Mac layout**，
即 Option → Alt、Command → Win；可按自己的习惯选择另一种映射。

## 验证清单

1. 在 Mac 和 Windows 各测试一次左、右桌面切换和静音，确认只影响鼠标所在电脑。
2. 按住静音键，确认只切换一次；松开后再按应再次切换。
3. 按住桌面切换键并将鼠标移回另一台电脑，松开时不应泄漏 F13/F14 到应用。
4. 测试水平滚动、普通滚动、后退、中键与 DPI，确认保留原有行为。
5. Windows 按住 Shift 等修饰键再切换桌面，随后继续输入，确认修饰键状态正常。
6. 关闭适配开关，确认 F13–F15 恢复普通按键行为。

这些修改是功能实现，不代表已经在 MR0089 实机上验证。Mac 睡眠自动移交、Windows 登录界面、
UAC 安全桌面及跨电脑剪贴板不在本次修改范围内。
